# AI-Based Crop Recommendation System — Streamlit Prototype

A small Streamlit interface for the Module 5 crop recommendation project. It loads the saved Random Forest model and metadata, accepts seven numeric inputs, checks for finite values, warns when values fall outside observed training ranges.

## Project structure

```text
Crop_Recommendation_Streamlit_Prototype/
├── app/
│   └── app.py
├── models/
│   ├── crop_recommendation_rf.pkl          # copy from notebook output
│   └── crop_recommendation_metadata.json   # copy from notebook output
├── requirements.txt
└── README.md
```

The model and metadata files are not embedded in this package because they must be generated by running the project's training notebook. The application stops with a helpful message if either file is missing.

## 1. Create the model artifacts

Run the Module 5 notebook through its final model-saving cell. It should save:

- `crop_recommendation_rf.pkl`
- `crop_recommendation_metadata.json`

Copy both files into the `models/` directory in this project. The metadata should include the feature order and observed training ranges, as generated by the notebook.

## 2. Set up Python

Python 3.10 or 3.11 is recommended.

Create and activate a virtual environment from this project's root directory:

### Windows (PowerShell)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### macOS / Linux

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 3. Run the application

From the project root:

```bash
streamlit run app/app.py
```

Streamlit will print a local URL, usually `http://localhost:8501`. Open it in a browser.

## Input fields

| Feature | Description |
|---|---|
| `N` | Nitrogen |
| `P` | Phosphorus |
| `K` | Potassium |
| `temperature` | Temperature in °C |
| `humidity` | Relative humidity (%) |
| `ph` | Soil pH |
| `rainfall` | Rainfall in mm |

The fields are text inputs so the application can clearly reject blank, non-numeric, `NaN`, and infinite values. Values outside the saved observed training range trigger a warning but do not automatically block prediction.

## Output

- Predicted crop class
- Maximum predicted class probability (displayed as model confidence)

The displayed probability is a model output, not a guarantee of crop success or necessarily a calibrated real-world probability.

## Troubleshooting

- **Model/metadata missing:** run the notebook's model-saving cell and copy both output files to `models/`.
- **Feature-name/order error:** ensure metadata `features` matches the training feature names and order.
- **Dependency issue:** use a fresh virtual environment and install the listed requirements.
- **Untrusted model file:** only load `.pkl` files created by your own trusted training process. Pickle/joblib files can execute code when loaded.

## Responsible use and limitations

The model is trained on a dataset with 2,200 records and 22 crop classes, as described in the Module 5 report. It does not include every relevant factor, such as location, seasonality, soil texture, crop history, pests, or diseases. Treat predictions as decision support and consult local agronomists or agricultural extension professionals before making planting decisions.
